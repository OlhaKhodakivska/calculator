# 🧮 Calculator (Vanilla JavaScript)

A simple and functional **calculator application** built using **HTML, CSS, and Vanilla JavaScript**.

This project was developed as a **homework assignment for Prog Academy**, focusing on DOM manipulation, event handling, and basic application state management without frameworks.

# 🛠️ Technologies Used

## 🌐 HTML5
- Semantic markup structure
- Clean layout for calculator grid
- Accessible button-based interface

## 🎨 CSS3
- Gradient backgrounds for realistic UI depth
- Box-shadow & inset shadows for 3D effect
- Button press animations (active states)
- Responsive layout design

## ⚙️ JavaScript (Vanilla JS)
- DOM manipulation (`querySelector`, `addEventListener`)
- Event-driven architecture
- Core arithmetic logic:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Application state handling:
  - Current input value
  - Operator tracking
  - Result storage
- Memory functions:
  - `M+`
  - `M-`
  - `MRC`

---

# ✨ Features

- ➕ Basic arithmetic operations
- 🔢 Decimal number support
- 🧹 Clear button (`C`)
- 🧠 Memory system (M+, M-, MRC)
- 🖥️ Read-only display (prevents manual input)
- 🎯 Button-based interaction only
- 📱 Responsive layout behavior

---

# 🎯 Project Purpose

This project was created to practice and strengthen core frontend fundamentals:

- DOM manipulation without frameworks
- Event-driven JavaScript logic
- State management in vanilla JS
- UI styling with CSS (including pseudo-3D effects)
- Building interactive interfaces from scratch
